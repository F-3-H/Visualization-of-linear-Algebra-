LINEAR ALGEBRA · SPAN

张成 SPAN LAB

一组向量，能走出多大的空间？
写下方向与数量，点一下，看它们把空间铺到第几维。

span(v₁, …, vₙ) = { Σ cᵢvᵢ | cᵢ ∈ ℝ }

输入坐标，点「展现张成空间」。整数组合的点阵是"所有线性组合"的可见骨架。

纯本地运行 · 无外部依赖 · 二维 / 三维

方法说明

张成，是一组向量能走到的全部地方

取一组向量 v₁ … vₙ，把所有可能的线性组合 c₁v₁ + … + cₙvₙ 收集起来，得到的集合就是它们的张成 span(v₁, …, vₙ)。它一定过原点，因为所有系数取 0 就回到原点。

二维

0 维 · 一个点

只有零向量（或没有向量）。没有方向可走。

二维

1 维 · 一条直线

所有向量共线。再多写几个，也只是同一条线。

二维

2 维 · 整个平面

只要有两个不共线的方向，平面上的每一点都能被组合出来。

三维

2 维 · 一张平面

三维里的两个独立方向铺出一张过原点的平面；第三个向量若落在面内，不增加维数。

三维

3 维 · 整个空间

三个方向不共面时，它们撑满整个 ℝ³。行列式不为零是这件事的代数判据。

通用

向量多，不等于维数高

张成的维数等于这组向量的秩。多出来的向量若能被前面的向量表示，就不会扩大空间。

怎么读这个页面

  • 坐标支持整数、小数、分数，例如 2、-1.5、3/4。
  • 向量个数可以随时增删。第一次点「展现张成空间」后，修改坐标会即时更新；再点一次会重演展开动画。
  • 点阵画的是整数系数组合 i v₁ + j v₂ (i, j ∈ ℤ)，它们必须全部落在张成空间里——这是"张成"最直观的见证。
  • 拖拽二维平移、三维旋转；滚轮缩放；双击画布或点「重置视角」回到默认视角。
  • 组合探针打开后，可以手动拖动每个系数，观察组合点是否始终停留在张成空间内。

页面完全离线运行，不加载任何外部脚本或字体。

# 张成 · Span Lab

> 一组向量，能走出多大的空间？

一个**零依赖、可离线运行**的二维 / 三维张成（span）交互可视化。写下任意几个向量，点「展现张成空间」，看它们张成的是一个点、一条直线、一张平面，还是整个空间。

> 本项目位于独立的 `span-lab/` 目录，与 `E:\线性代数` 下已有的文章、配图和其他项目**不共享代码、样式或资源**；它是一次全新的、独立的生产。

## 能做什么

| 能力 | 说明 |
|---|---|
| 双工作区 | 二维、三维各一套独立的向量、视角与结果；互不干扰 |
| 向量数量 | 0–8 个，可随时增删；0 个向量时张成就是原点 |
| 坐标输入 | 整数、小数、分数（`3/4`、`-1.5`、`1e-3`），也支持 Unicode 负号 `−` |
| 一键展现 | 点「展现张成空间」；首次展现后，改坐标会即时重算，再点一次重演展开动画 |
| 结果判读 | 张成类型、维数、秩、冗余向量数、逐步独立性、子空间方程 / 参数式、矩阵与秩 |
| 三维观察 | 拖拽旋转、滚轮缩放、双击 / 「重置视角」 |
| 二维观察 | 拖拽平移、滚轮缩放、双击 / 「重置视角」 |
| 组合探针 | 拖动 `c₁ … cₙ`，看 `Σ cᵢvᵢ` 是否始终落在张成空间里 |
| 整数组合点阵 | 把「所有线性组合」变成可数的点与网格：一维是等距刻度，二维是斜网格，三维是格线点阵 |

## 数学约定

- 向量按**列**组成矩阵 `A = [v₁ v₂ … vₙ]`；张成的维数等于 `rank(A)`。
- 秩用带相对容差（`1e-9`）的高斯—约当消元（RREF）计算，避免浮点噪声把共线判成平面。
- 结果类型：
  - 2D：0 维原点、1 维直线（`ax + by = 0`）、2 维整个 `ℝ²`；
  - 3D：0 维原点、1 维直线（参数式）、2 维平面（`ax + by + cz = 0`）、3 维整个 `ℝ³`。
- 对每个向量按输入顺序做增量秩判定：秩增加记为「独立」，否则记为「相关」，并解出它由前面独立向量表示的系数。
- 基本胞元：`rank = dim` 时显示 `|det|`（面积 / 体积）；3D 的 2 维平面显示基本平行四边形的面积。
- 点阵：对独立基向量取整数系数组合（2D 二维平面 `i,j ∈ ℤ`，3D 空间 `i,j,k ∈ ℤ`），只画落在视域内的点。

## 扩展点

代码按「数学 / 渲染 / 界面」三层分开，便于后续扩展：

1. **新增维度**：`span-math.js` 的 `spanInfo` 已按 `dim` 参数工作；主要工作在新渲染器与轴/预设配置。`WorldPanel` 可按 `dim` 实例化。
2. **新增预设 / 示例**：在 `app.js` 的 `PRESETS` 中追加，不需要改渲染器。
3. **新增视觉层**：在 `scene2d.js` / `scene3d.js` 的 `render()` 中按顺序追加；两者都暴露 `stats`，便于写新的渲染断言。
4. **新增分析维度**：`spanInfo` 已给出 `basis / increments / equation / measure`；可在 `app.js` 的 `updateAnalysis` 中追加零空间、投影、基变换等内容。
5. **持久化 / 分享**：把每个 `WorldPanel.state` 序列化到 URL hash 或 localStorage；界面层不需要重写。
6. **验收扩展**：给新渲染层加 `stats` 字段，在 Node 里用假 canvas 断言；复杂的呈现层再交给真实浏览器截图或 CDP。

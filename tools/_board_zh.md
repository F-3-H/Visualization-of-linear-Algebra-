### [2026-10-14] 判据落到"读数能复算的范围"之外时，要换一个在退化附近仍单调可读的量报给读者——而不是放宽阈值或干脆不报

- 假设/观察：这一轮的交付是一个五视角交互项目 + 一篇正文（线性代数基础·控制论篇：立在掌心的棍子）。其中一个视角要读者把"力从哪儿进去"（一列 b）拖到两根特征方向上去，看"有一个方向够不着"这件事。读数里给出的判据是面积 det[b, A·b]，面积塌到 0 就是够不着。

- 实践结果：**判据本身没错，错的是它印出来的位数。**"够不着"是 1e−9 尺度上的**一处点、不是一个区域**（b 必须精确落在特征方向上；四舍五入到小数点后三位就变成 1e−4，那一格就再也摸不到）——而读数只能印有限位数。于是出现一种很别扭的状态：**读数里的判据是对的，读者却永远照着读数复算不出那个 0**。验收侧最初也栽在这里：C 组拿"读数里那个只印到三位小数的 b"去独立复算，得到 7e−5 而不是 0，看着像页面算错了——其实是**验的方法**把舍入当成了事实。两处修法都不是放宽阈值：① 页面读数里**补印一个在退化附近仍然单调、且照着读数就能自己复算的量**（这一轮补的是 b 与 A·b 两列之间的夹角，按"两条直线"折到 0–90°，因为 b 对准"回来"那条线时两列反向、atan2 给出 180°）；② 验收拆成两条各自站得住的核对——读数的**自洽**（说够不着，就必须同时给出 0 面积与 0 夹角）与读数跟**精确特征方向**的核对，而不是跟舍入后的 b 核对。

- 结论：**"判据对不对"与"判据在不在读数能复算的范围里"是两件独立的事。** 判据一旦是某个量的**等号**（det = 0、夹角 = 0、秩亏、奇点），而那个量又要印给读者看，就必须同时满足两条：所印的位数能让读者把那个等号复算出来，或者另印一个**在等号附近仍单调可读**的量把这条信息带出去。取景那条老规矩说的是"读数里量得出的，图上必须看得见"；这一条是它的另一半：**图上看得见的，读数里也得算得出**——两句话合起来才是"读数与画面同源"的完整形态。附一条给验收侧的推论：**当判据是一个等号时，拿舍入后的读数去复算，得到的必然是"看起来不对"，这不是发现缺陷，这是验法自带的假阳性。**

- 状态：待验证假设（一轮实践；页面侧与验收侧两处都实测并各自修完，正向 394/0、反向对照 174 条报错且 A/B/C/D 四组都抓得住。判据清晰、可复现："任何印给读者的判据，问一句——照着这行字，读者能不能自己把那个等号算出来？"）

- 对理论的修正建议：无。与既有"取证阶梯按可信度排序"相接：本条补的是阶梯的**底边**——先把"读者照着交付物本身能不能复算"这件事管住，再谈更高一级的取证手段。

### [2026-10-14] 数值全绿而措辞整体写反：一句话里的每个部分都要各有独立来源，只在数字上求互证等于给措辞留了一块无人核对的地方

- 假设/观察：同一个交付（五视角交互项目 + 配图）的语义验收，做法是"页面读数 ↔ Node 侧按同一组输入独立复算"，四类断言：判词一致、两个倍数一致、关键量一致、误差量为 0。

- 实践结果：**四类数值断言全部为真，而交付物上的话有四处是错的。** 三处同一个病：把 b 拖到两根特征方向上时，读数那一句里同时含有**结论**（"还救得回来"／"没救了"）与**那条线的名字**（"跑掉"／"回来"），而这两部分分属两个判断——结论由"纹丝不动的那个倍数的正负"给出，名字却是照结论那一支随手写死的字面量，于是**名字整体写反、结论一个没错**。这个错法在数值上完全不可见：面积确实是 0、夹角确实是 0、纹丝不动的那个倍数确实等于原值——**四类断言没有一条碰过"页面给自己那句话起的名"**，而 C 组当时也没有任何一条断言是"从几何独立算出该叫什么、再回头核对页面上印的字"。第四处更隐蔽：配图脚本里两个面板各要标一个"纹丝不动的那个倍数"，我用**手写的序号**指定它，而序号与"算出来的两个倍数里哪个没变"之间没有任何可核对的关系——一标就反了，且图是静态 png，事后没有任何一层能自动发现它。

- 结论：**同一个判断在交付物上出现的每一种形态（数字、判词、名字、颜色、图例下标），都要各有各的独立来源。** 本轮补的三条：① 命名类的量也要由外部从几何独立算出再回头核对页面上的字（这一轮新增的反向故障就是"把读数里两条线的名字对调"，装回去后语义组立刻报出 2 条）；② 凡是**手写的位置／序号／标签**与**算出来的对象**配对的地方（面板序号、图例下标、颜色分组），要么让配对本身能被数值核对，要么干脆取消手写（本轮改成"拿被标示的那个数值反查它的下标"——一次查找换掉一次手写）；③ 两句判断不要合成一句写，合成之后其中一个错的时候，另一个会替它打掩护。

- 状态：待验证假设（一轮实践里三处实测并各补上能抓住它的断言；"名字对调"这一条反向故障实测能让语义组报错，即判据不是空转的。第 ② 条只在一份渲染脚本上一次实测）

- 对理论的修正建议：无。与既有"互证的价值来自路径的独立性"相接：本条把"独立性"从**数的独立性**扩到**措辞的独立性**——**只要一处判断在交付物上有多种形态，就按形态各要一条独立来源；只在数字上求互证，等于认定"数对了话就对了"，而这句话本身从没被验过。**
